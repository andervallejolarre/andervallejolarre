## Ander Vallejo Larre

Full-stack developer (React, Node.js, React Native) with roots in digital arts and interactive systems. I've spent years building immersive experiences that blend code, media and electronics; now I bring that same creative and technical mindset to web and mobile development.

### Apps & Tools

**[DigitalPlant](https://github.com/andervallejolarre/web_app_project)** — A full-stack gamified plant companion app (React + Express + MongoDB) that pulls live weather data from your location to simulate real growing conditions. 

**[LabelTracker](https://github.com/andervallejolarre/mobile_app_project)** — Mobile app (React-Native + Expo + express) that connects to the Discogs database, to search and follow record labels, browse a live feed of their latest releases, and build a personal library of saved labels and records.

### Learning Exercises
**[Task Manager API (AI Re-Built)](https://github.com/andervallejolarre/task_manager_api_ai)**

**[Task Manager API](https://github.com/andervallejolarre/task_manager_api)** - A REST API for user registration, authentication, and personal task management, built with TypeScript, Express, MongoDB, and JWT.

**[Cloning Front-end](https://github.com/andervallejolarre/04_ny_times)** — Front-end replication of the New York Times homepage (HTML + CSS) — focused on mastering grid/flexbox layouts, typographic hierarchy, and the structural complexity behind a large-scale editorial design.

### WIP

**[Plantatum](https://github.com/andervallejolarre/plantatum)** — An ongoing hardware/software project combining Arduino-based biosensing, digital fabrication, and Pure Data to capture live bioelectrical signals from plants and map them into real-time generative art.
